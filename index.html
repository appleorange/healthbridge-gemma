HealthBridge

Local AI health insurance navigator for immigrants

View on GitHub Get Started
🔒  Runs entirely on your device. No data sent anywhere. · Powered by Ollama + Gemma 4

HealthBridge is an AI-powered health insurance navigator built for US immigrants and visa holders. Answer a short questionnaire about your immigration status, income, and situation — and get a personalized insurance recommendation, real ACA plan comparisons, an enrollment timeline, and tools to parse documents, check provider networks, and appeal claim denials.

Everything runs locally via Ollama with Gemma 4. No account, no cloud API, no data collection — your immigration status and health information stay on your device.

Get started

1

Install Ollama from ollama.com

2

Pull the model

ollama pull gemma4:e4b
3

Clone the repo and install dependencies

git clone https://github.com/appleorange/healthbridge-gemma && cd healthbridge-gemma && npm install
4

Start the app and open localhost:3000

npm run dev
